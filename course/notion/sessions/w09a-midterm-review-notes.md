## Q08 · Item-CF의 평점 출처

**객관식 · 5점**

R의 행은 차례로 U1·U2·U3이고, 열은 A·B·C·D 영화이다. None은 미관측이며 인덱스는 0부터 시작한다. `[식 for 값 in 목록]`은 목록의 각 값에 식을 적용해 새 목록을 만든다. U2의 C 평점을 아이템 기반 CF로 예측할 때 A와 B를 이웃 영화로 사용한다고 하자. 다음 코드와 그 해석에 관한 옳은 설명을 모두 고르시오.

```python
R = [
    [5, 1, 4, None],
    [2, 5, None, 4],
    [4, 2, 1, 3]
]
target_user = 1
neighbor_cols = [0, 1]
neighbor_ratings = [R[target_user][j] for j in neighbor_cols]
item_vector = [row[2] for row in R]
print(neighbor_ratings)
print(item_vector)
```

① `neighbor_ratings`는 영화 A를 평가한 서로 다른 두 사용자의 평점이다.

## Q15 · MF 예측과 관측 손실

**단답형 · 5점**

한 학습 관측의 실제 평점은 $r=4$이고, 현재 MF 모수는 다음과 같다. 평균 $\mu$는 이미 학습자료에서 정한 값이며 이번 계산에서 고정한다.
$$\mu=3,\quad b_u=0.2,\quad c_i=-0.1,\quad p_u=(0.2,0.4),\quad q_i=(0.5,0.5),\quad\beta=0.2.$$
다음 식으로 **예측 평점 $\hat r_{ui}$와 이 관측 한 건의 전체 손실 $\ell_{ui}$**를 구하시오. 예측을 1–5 범위로 제한하는 clipping은 적용하지 않는다. 풀이에는 내적, 잔차, 데이터 손실과 정규화 항을 구분하여 나타내시오.
$$\hat r_{ui}=\mu+b_u+c_i+p_u^\top q_i,\qquad e=r-\hat r_{ui},$$
$$\ell_{ui}=\frac12e^2+\frac\beta2\left(\|p_u\|^2+\|q_i\|^2+b_u^2+c_i^2\right).$$

### 평가 기준 · 합계 5점

## Q19 · SGD의 동일 시점 갱신

잠재요인이 하나인 MF에서 정규화 강도는 0이다. 다음 관측의 **갱신 전 잔차**는 이미 `error=1.0`으로 계산되었다. 이번에는 잔차를 다시 계산하지 않고 p와 q만 갱신한다. 수업의 규약은 다음 두 식의 오른쪽에 모두 갱신 전 값을 사용하는 것이다.
$$p_{new}=p_{old}+\alpha e q_{old},\qquad q_{new}=q_{old}+\alpha e p_{old}.$$
아래 코드는 이 규약을 어긴다.

(가) p 갱신 **전에 추가할 저장 코드 한 줄**과 **q 갱신을 대체할 코드 한 줄**을 쓰시오. p의 갱신 줄은 유지한다.

```python
p, q = 0.6, 0.5
error, alpha = 1.0, 0.1
p = p + alpha * error * q
q = q + alpha * error * p
print(round(q, 3))
```

## Q20 · 검증 최적 epoch와 상태 복원

**단답형 · 5점**

아래의 `val[e]`는 epoch e의 검증 RMSE이고 **epoch 0은 갱신 전 초기 상태**다. 모든 epoch의 학습을 이미 마쳤다. 검증 RMSE가 최소인 epoch를 고르되, **동점이면 먼저 나온 epoch를 유지**한다.

`snapshots[e]`에는 해당 epoch의 학습 모수 전체가 저장되어 있다. 제공 함수 `copy_state(x)`는 x의 모든 배열을 서로 독립된 복사본으로 만들어 반환한다. 이 함수의 구현이나 이름을 외울 필요는 없다.

(가) 빈칸에 들어갈 비교 연산자, (나) 출력되는 epoch 번호, (다) test 평가 전에 선택한 epoch로 함께 복원해야 하는 학습 모수 **네 종류**를 쓰시오.

```python
val = [1.12, 0.94, 0.94, 1.02]
best = 0
for epoch in range(1, len(val)):
    if val[epoch] ____ val[best]:
        best = epoch
model_state = copy_state(snapshots[best])
print(best)
```

| 평가 항목 | 인정 조건·부분점수 | 배점 |
|---|---|---:|
| 비교 연산자 | 지문의 최솟값·동점 처리 규칙을 충족하는 연산자를 제시합니다. | 1.5점 |
| epoch 추적 | 자신이 제시한 비교에 따른 실행 결과를 정확히 추적한 경우를 구별하여 인정합니다. | 1점 |
| 복원 모수 · 항목 I | 원 채점표의 첫 두 종류를 요구한 전체 모수의 범위로 명시하면 각각 0.75점. | 1.5점 |
| 복원 모수 · 항목 II | 원 채점표의 나머지 두 종류를 구체적으로 명시하면 각각 0.5점. | 1점 |

비계산 코딩 단답입니다. 연산자·epoch·네 모수 종류로 충분하며 별도 수치 풀이 박스를 요구하지 않습니다. 복원 대상은 연산자와 독립적으로 채점합니다. 종류 없이 ‘모든 파라미터’라고만 쓰면 복원 항목 합계에서 1점만 인정합니다.

# 딥러닝응용I(추천시스템)

동덕여자대학교 데이터사이언스전공 · 2026학년도 2학기  
담당교수: 유원상  
화·목 10:30-11:45

## 이 강의에서 배우는 것

추천시스템은 사용자의 선택을 대신 정하는 기술이 아니라, 방대한 후보 가운데
각 사용자에게 의미 있을 가능성이 높은 항목을 찾아 **발견을 돕는 의사결정 시스템**입니다.

이 강의는 다음 흐름으로 진행됩니다.

1. 인기 기반·내용 기반 추천과 평가
2. 협업 필터링
3. Matrix Factorization과 Factorization Machines
4. 딥러닝·AutoEncoder·Transformer 추천
5. LLM과 하이브리드 추천
6. cold start, scalability, implicit feedback 등 실제 구축 이슈

## 수업 방식

각 수업은 일반적으로 다음 네 단계로 구성됩니다.

1. 핵심 질문과 실제 사례
2. 이론과 수식의 직관적 설명
3. Google Colab 실습과 미니 추천 애플리케이션
4. 직접 코딩·디버깅·해석·퀴즈

## 강의 페이지

각 수업 자료는 `sessions` 폴더에 차례대로 추가됩니다. Notion import 후에는
이 목록을 Notion 페이지 링크로 다시 연결합니다.

- Week 1A — 오리엔테이션과 추천시스템의 세계
- Week 1B — Colab 환경 구축과 첫 추천 앱

## 평가

- 중간고사 30%
- 기말고사 40%
- 과제 10%
- 출석 20%

실습 과제는 통과 10점 또는 탈락 0점으로 평가합니다.

## 학습 원칙

코드를 실행한 결과보다 **왜 이 추천이 만들어졌는지**, **어떻게 평가할지**,
**어떤 사용자를 놓치고 있는지**를 설명하는 능력을 중요하게 봅니다.

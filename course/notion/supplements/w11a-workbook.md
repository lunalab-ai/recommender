# W11A · 계산·수정 워크북

**딥러닝응용I(추천시스템) · 동덕여자대학교 · 유원상 교수 · 2026-2 · 2026-11-10**

풀이 예제를 본 뒤 **예상 → 자신의 계산 → 코드 출력 → 달라진 단계 → 이유 한 문장**을 기록하세요. W01–W04는 7장 복습과 순차 데이터 연결, W05–W08은 8장의 계산·구현·평가입니다. 새로운 채점 과제나 제출 기한은 없습니다.

## W01 · 입력과 관측 여부

평점 $[4,2,\mathrm{NaN},3]$, 주어진 훈련 평균 3입니다. 중심화 입력과 관측 마스크를 각각 적으세요. 두 종류의 0이 어느 위치에 생기는지 설명하세요.

힌트: 원자료의 관측 여부를 먼저 보존하고, 관측값에서만 평균을 뺍니다.

내 입력: __________　내 마스크: __________　두 0의 의미: ____________________

자가 점검: 관측 수가 원래 평점 개수와 같은지 확인하세요. 대응 코드: 7A `fixed_ae_forward`.

## W02 · 손실의 분자와 분모

중심화 정답 $[1,0,-1]$, 예측 $[.5,8,0]$, 관측 마스크 $[1,0,1]$입니다. 관측 제곱오차 합·관측 수·MSE·RMSE를 구하세요. 미관측 위치의 큰 예측 8을 오차에 넣어야 하는지도 설명하세요.

힌트: 제곱근을 취하는 순서와 관측 수로 나누는 순서를 구분합니다.

SSE: ______　관측 수: ______　MSE: ______　RMSE: ______　이유: ______________

자가 점검: 각 위치의 포함/제외를 먼저 표시하세요. 대응 코드: 7A/B `observed_reconstruction_loss`.

## W03 · 한 가중치 갱신

$\hat y=wx$, $x=1$, $y=1$, $w=.2$, $L=(y-wx)^2$, 학습률 .1의 SGD입니다. 갱신 전 예측·손실, $\partial L/\partial w$, 새 $w$, 새 손실을 구하세요.

힌트: $\partial L/\partial w=-2x(y-wx)$를 대입합니다. 실제 Adam/Adamax의 갱신 숫자와 같다고 가정하지 않습니다.

예측/손실: __________　기울기: ______　새 가중치: ______　새 손실: ______

자가 점검: 같은 입력을 다시 예측했을 때 손실이 어떻게 바뀌었는지 확인하세요.

## W04 · 접두 쌍과 내부 ID

내부 ID 이력이 `[1,2,3,4,5]`, 최소 접두 길이 2, 배열 길이 3입니다. 세 입력·정답 쌍을 적으세요. 원본 ID 101·205·999가 내부 ID 1·2·3에 대응할 때, 예측 내부 ID 2를 다음 입력에 넣는 값과 표시용 원본 ID를 구별하세요.

힌트: 긴 이력은 최근 3개만 남기고, 짧은 이력은 뒤를 0으로 채웁니다.

쌍1: ____________________　쌍2: ____________________　쌍3: ____________________

모형에 추가할 값: ______　표시용 값: ______　정답을 입력에서 뺀 이유: __________

자가 점검: 현재 정답이 해당 입력에 들어가 있지 않은지 확인하세요. 대응 코드: 8B `pad_history`, `prefix_pairs`.

## W05 · attention을 끝까지 계산

$$
q=[1,0],\quad K=\begin{bmatrix}1&0\\0&1\end{bmatrix},\quad
V=\begin{bmatrix}4&0\\0&2\end{bmatrix}.
$$

내적 → $\sqrt2$로 나누기 → softmax → V 가중합을 계산하세요. 계산기 사용이 가능합니다.

점수: __________　스케일 점수: __________　가중치: __________　출력: __________

힌트: 지수값을 각 행의 합으로 나눕니다. 가중치 합과 출력 두 성분을 따로 점검하세요.

자가 점검: 모형을 학습한 결과인지, 주어진 수치의 순전파인지 구분하세요. 대응 코드: 8A `scaled_attention`.

## W06 · 마스크와 모형 크기

W05의 query가 첫 위치이고 인과 마스크로 두 번째 위치를 가렸습니다. 새 가중치와 출력은 무엇인가요? 패딩 마스크와 가리는 이유가 어떻게 다른가요?

입력폭 16, 헤드 2, 헤드당 `key_dim=8`인 경우 내부 연결 폭과 출력 투영 뒤 폭도 적으세요.

가중치/출력: ____________________　마스크의 두 목적: ____________________

내부 연결 폭: ______　최종 출력 폭: ______

자가 점검: ‘key_dim은 전체 폭’이라고 읽지 않았는지 확인하세요.

## W07 · 교차엔트로피와 실제 학습 코드

아이템 확률 $[.1,.7,.2]$, 정답은 두 번째입니다. CE를 계산하고 one-hot 정답과 정수 정답 표현을 적으세요. 이어 8B `sequence_train_step`에서 손실 계산·기울기·모수 갱신 줄을 표시하세요.

CE: ______　one-hot: __________　정수 라벨: ______

세 코드 위치: ____________________　실제 바뀌는 상태: ____________________

자가 점검: `model(x)`를 호출한 것만으로 학습했다고 설명하지 않았는지 확인하세요.

## W08 · 평가·한 조건 수정·앱 연결

추천 `[5,7,9]`, 보류 정답 `[9,5,2,4]`입니다. P/R/F1을 계산하세요. 알려진 이력에 5가 있었다면 ‘관측 이력 제외’ 규칙을 지켰는지도 확인하세요.

P: ______　R: ______　F1: ______　후보 규칙 확인: ____________________

실제 실습에서는 이력 길이·헤드 수·학습률 중 하나만 바꾸는 실험을 설계하세요. 동일하게 유지할 조건과 검증 선택 기준을 적습니다. 앱의 `candidate_fn` 전달 위치를 찾아 수정한 규칙이 추천표와 CSV에 반영되는지 확인하세요.

| 조건/관측 | 기본 | 변경 |
|---|---|---|
| 내가 바꾼 한 조건 | | |
| 사용자 분리·seed·자료 모드 | | |
| 모수 수·갱신 수·학습 시간 | | |
| 검증 CE와 선택 epoch | | |
| 선택 후 시험 P/R/F1 | | |
| 앱·CSV 변화와 이유 | | |

자가 점검: 미래 정답으로 후보를 고르거나 시험 결과로 설정을 다시 선택하지 마세요. 성능이 나빠져도 원인과 조건을 정확히 설명하면 유효한 비교입니다.

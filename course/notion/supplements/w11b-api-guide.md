## 시작과 복구

자신의 Colab 사본을 저장하고 CPU로 첫 셀부터 실행합니다. 최초 공식 Ollama 실행 파일과 두 모델은 약2.2GB, 공식 리뷰 압축파일은 약5.3MB입니다. 네트워크·CPU에 따라 준비 시간이 달라집니다. 모델·입력 해시를 확인한 뒤 같은 캐시를 재사용합니다. API 키는 필요하지 않습니다.

다운로드 실패는 해당 준비 셀을 다시 실행합니다. 설치 갱신/이미 로드한 의존성 버전 충돌 안내가 나오면 런타임 재시작 후 처음부터 실행합니다. 동시 실행 제한은 자신이 사용하지 않는 런타임을 확인한 후 해제합니다. 메모리/프로세스 오류를 정답·무작위 벡터로 우회하지 않습니다. 생성 모델의 잘못된 제품ID는 검증 출력에서 확인하고 기록하세요.

## 본문에서 읽고 수정할 핵심 함수

| 함수 | 입력 → 출력 | 실제 역할·상태 변화 |
|---|---|---|
| build_prompt | 과거만 담은 case, CF/CB, 예시수/길이 → messages 2개 | 요청 내용을 만듦; 가중치 갱신 없음 |
| validate_recommendations | 실제 JSON, 후보, 관측, K → 유효/거절 목록 | 부족분을 임의로 채우지 않음 |
| ranking_overlap | 유효 목록, 보류 정답, 요청K → P/R/F1 | 평점RMSE와 다른 문제; precision 분모 K고정 |
| aggregate_reviews | train행, 집계기준 → 텍스트/원본행/생략문자 | 최근3개·각300자; 시험 리뷰 사용 금지 |
| normalize_embeddings | 실제 N×768, d → N×d | 앞d선택 후 행별L2; PCA가 아님 |
| assemble_features | user,item,recipe → x:(U+I+2d,) | 원핫 두 블록 + 임베딩 두 블록 |
| fm_score | x,w,V,b → 항별 예측 | 본문 효율식; 갱신 없음 |
| embedding_fm_step | x,y,w,V,b,α → 새w/V,오차/손실 | 같은 갱신 전 모수로 SGD; b고정·L2=0 |
| fm_epoch | X,y,state,순서 → 새state | 본문의 한 관측 갱신 반복 |

`fit_embedding_fm`의 준비·검증 선택은 모듈에 두되 위 feature/epoch/step/score 함수를 **명시적으로 전달**합니다. 학생이 수정한 함수를 읽기만 하는 것이 아니라 실제 학습과 앱이 호출합니다. `run_prompt`에도 prompt/validator/metric 함수를 전달합니다.

## 실습 A · 요청부터 검증까지

1. 준비 → 대상/후보/보류 분리 확인 → 펼쳐진 함수 읽기.
2. CF/CB 실제 요청 → 원래 JSON·거절 이유·유효 목록·지표 읽기.
3. P01–P03 기록 → 함수 한 줄 수정 → 요청 다시 실행.
4. 앱 다시 조립 → 실제 요청 → 마지막 표 CSV 저장.

모델이 같아도 입력이 바뀌면 결과가 달라질 수 있습니다. 결과가 같으면 요청 해시와 실제 토큰 수를 확인합니다. 원문 리뷰·원래 사용자 식별자는 공유 앱에서 표시하지 않습니다.

## 실습 B · 실제 임베딩과 학습

1. 분할 → 훈련 리뷰만 집계 → 실제768차원 인코딩/캐시 확인.
2. 합성 벡터·특성·FM 예측·SGD를 손계산하고 검산.
3. 같은 분할에서 두 FM 학습 → 검증 선택/최적 상태 복원.
4. 한 조건 수정 → 검증 비교 → 최종 고정 후 시험 결과 확인.
5. 앱의 예측 분해 → CSV와 표시표 동일성 확인.

캐시 키가 바뀌는 조건은 모델digest·텍스트·훈련행·d·집계/정규화 함수입니다. 학습률 변경은 새로운 임베딩을 요구하지 않습니다. 미관측 ID는 원핫0·훈련평균 표현과 별도 flag로 표시합니다.

## 앱을 다시 조립해야 하는 이유

본문 함수를 다시 정의해도 이미 만든 앱은 이전 함수/모델을 가지고 있을 수 있습니다. **함수 → 인코딩/특성(필요 시) → 학습 → 앱 조립** 순서로 다시 실행합니다. 앱에서 조건만 바꾸고 계산 버튼을 누르지 않았다면 표는 이전 결과입니다. CSV는 그 마지막 표를 그대로 저장하며 추론을 다시 실행하지 않습니다. 공유 주소는 런타임 종료 시 만료됩니다.

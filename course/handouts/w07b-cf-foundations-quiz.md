# W07B ·협업 필터링 3~4주차 핵심 복습과 60문제 · 퀴즈 답안

> 딥러닝응용I(추천시스템) · 동덕여자대학교 · 유원상 교수 · 2026-2

먼저 강의자료의 점검 퀴즈를 풀고 확인하세요. 서술형 문항은 같은 의미의 다른 표현도 가능합니다.

이 답안은 해당 강의의 설명을 바탕으로 정리한 학습용 해설입니다.

## 1. 그림 1에서 u1의 미관측 영화 열을 추가하면 관측 평균이 바뀌나요?

변하지 않습니다. 새 관측이 없어서 평균의 분자와 관측 분모가 같습니다.

## 2. 그림 2에서 벡터의 양의 배율과 코사인은 어떤 관계인가요?

양의 배율은 분자와 길이곱에 같은 비율로 반영되어 상쇄됩니다. 두 비영벡터의 방향은 유지됩니다.

## 3. 그림 5의 정규화 비중 합과 기여도 합은 각각 무엇인가요?

정규화 비중의 합은1, 기여도의 합은 설명 예제의 예측3.5입니다.

## 4. 그림 7의 0.2는 별점 예측인가요, 보정량인가요?

보정량입니다. 대상 평균3을 더하면 예측3.2가 됩니다.

## 5. 그림 9에서 validation과 test를 구분하는 이유는 무엇인가요?

validation은 설정 선택, test는 설정을 확정한 뒤 최종 평가에 사용합니다. test를 보며 고르면 독립 최종 평가가 아닙니다.

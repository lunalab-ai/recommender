이 답안은 해당 강의의 설명을 바탕으로 정리한 학습용 해설입니다.

## 1. 내용 기반 추천과 협업 필터링은 각각 어떤 정보를 이용해 유사성을 판단하는가?

내용 기반은 장르·줄거리 같은 아이템 속성을, 협업 필터링은 여러 사용자의 평점·행동 패턴을 이용한다.

## 2. 미관측 평점을 코사인 계산용 행렬에서 0으로 채워도 실제 0점으로 평균에 넣으면 안 되는 이유는 무엇인가?

미관측은 아직 모르는 값이다. 계산 편의를 위한 0 채움은 실제 0점 관측이 아니며, 평균에 포함하면 관측이 적은 사용자나 영화의 평균이 부당하게 낮아진다.

## 3. 전체 차원 코사인과 공통 평가 항목만으로 양쪽 노름을 계산한 코사인이 다른 값을 가질 수 있는 이유는 무엇인가?

전체 차원 방식은 각 사용자의 모든 관측 평점을 노름에 포함한다. 공통 항목 방식은 양쪽 노름도 교집합에 한정하므로 분자가 같아도 분모가 달라질 수 있다.

## 4. Pearson 상관계수가 정의되지 않는 두 가지 상황은 무엇인가?

공통 관측이 부족하거나, 공통 관측에서 한쪽 평점이 상수여서 편차의 길이가 0이면 정의되지 않는다. 값 0인 상관과 구별한다.

## 5. 두 행동 집합의 크기가 각각 4와 3이고 공통 항목이 2개라면 Jaccard 유사도는 얼마인가?

합집합 크기는 4+3−2=5이므로 2/5=0.4이다.

## 6. 기본 CF의 가중평균 분모에는 어떤 사용자의 유사도를 포함해야 하는가?

자신을 제외하고 목표 영화를 실제로 평가한 유효 사용자만 포함한다. 이 수업에서는 유사도가 양수인 평가자를 사용한다. 분자와 분모의 사용자 집합은 같다.

## 7. test 평점까지 포함하여 사용자 유사도를 계산한 뒤 같은 test로 RMSE를 구하면 왜 문제가 되는가?

평가 때 몰라야 할 정답이 유사도·평균에 반영되는 데이터 누수다. train만으로 학습한 뒤 test의 ID로 예측하고 실제 평점은 마지막 오차 계산에만 사용한다.

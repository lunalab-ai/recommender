# W02B · 기본적인 추천 방법 (2) · 퀴즈 답안

> 딥러닝응용I(추천시스템) · 동덕여자대학교 · 유원상 교수 · 2026-2

먼저 강의자료의 점검 퀴즈를 풀고 확인하세요. 서술형 문항은 같은 의미의 다른 표현도 가능합니다.

이 답안은 해당 강의의 설명을 바탕으로 정리한 학습용 해설입니다.

## 1. 집단×영화 평균의 분모는 집단 전체 인원수인가, 어떤 관측 수인가?

학습 집합에서 그 집단이 해당 영화에 남긴 관측 수다. 집단 전체 인원수를 분모로 쓰지 않는다.

## 2. 경사하강법 없이 평균을 계산하는 것도 지도학습이라고 할 수 있는 이유는 무엇인가?

평점 정답으로 제곱오차를 최소화하는 모수를 추정하기 때문이다. 평균은 그 닫힌 해이며 반복 최적화가 필수는 아니다.

## 3. MeanRatingPredictor 객체를 만든 직후와 fit 직후의 차이는 무엇인가?

생성 직후에는 설정만 있고 fit 후에는 학습 평균과 집단 매핑 등 상태가 생긴다. predict는 이 학습 상태를 조회한다.

## 4. predict에 test의 실제 평점이 필요하지 않은 이유는 무엇인가?

입력 ID와 이미 학습한 평균으로 추정하고, 평가자가 별도로 보관한 정답과 추정 결과를 비교하기 때문이다.

## 5. MovieLens 100K에서 교재의 줄거리 대신 장르를 사용한 이유는 무엇인가?

MovieLens 100K에는 줄거리 열이 없다. 별도 교재 데이터를 섞지 않고 동일 데이터에서 네 방법을 비교하기 위해 제공된 장르 특징을 사용했다.

## 6. 내용 프로필을 test에서 좋아한 영화까지 포함하여 만들면 어떤 문제가 생기는가?

가려 둔 정답 행동이 사용자 프로필에 들어가는 데이터 누수다. 평가 때 모르는 정보를 이용해 성능이 오염된다.

## 7. 평점 수와 코사인 점수를 RMSE에 바로 넣지 않고 순위 지표로 비교한 이유는 무엇인가?

평점 개수·코사인은 1–5점 예측 평점과 단위가 다르다. 공통 후보의 정렬 결과는 같은 순위 지표로 비교할 수 있다.

## 8. 내용 기반의 카탈로그 커버리지가 높다는 사실만으로 더 만족스러운 추천이라고 할 수 있는가?

커버리지는 전체 추천 영화의 범위다. 개인 목록 내 다양성, 정확도, 실제 만족도를 별도로 확인해야 한다.

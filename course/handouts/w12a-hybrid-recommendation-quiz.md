# W12A · 영화제 편성 실습과 하이브리드 추천 · 퀴즈 답안

> 딥러닝응용I(추천시스템) · 동덕여자대학교 · 유원상 교수 · 2026-2

먼저 강의자료의 점검 퀴즈를 풀고 확인하세요. 서술형 문항은 같은 의미의 다른 표현도 가능합니다.

이 답안은 해당 강의의 설명을 바탕으로 정리한 학습용 해설입니다.

## 1. CF 프롬프트의 N1과 CB 프롬프트의 R5는 각각 어떤 정보를 담나요?

N1은 비슷한 관객 한 명의 관람 영화 이력, R5는 후보 영화 M5의 리뷰입니다. 모형을 학습하지 않고 입력 자료를 다르게 줍니다.

## 2. 모델이 M1을 valid JSON의 picks에 넣었습니다. 어떤 조건을 위반했나요?

기본 관객이 M1을 이미 봤습니다. 형식을 맞춰도 콘텐츠 조건은 별도로 검사합니다.

## 3. 리뷰 벡터를 만드는 모델이 고정일 때 FM에서는 무엇이 학습되며 입력 폭은 얼마인가요?

관객20·영화10·양쪽 8차원씩이면 46열입니다. FM의 선형·쌍별 상호작용 모수는 훈련 평점으로 갱신합니다.

## 4. 실제 4점, CF 3점, MF 5점일 때 MF 비중이 0, 0.5, 0.8, 1이면 예측이 각각 얼마인가요?

순서대로 3, 4, 4.6, 5점입니다.

## 5. 두 모형이 모두 5를 예측하고 실제가 4라면 50:50으로 섞은 후 절대오차는 얼마인가요?

결합도 5이고 절대오차는 1입니다. 두 예측의 오차 방향이 같아 상쇄되지 않습니다.

## 6. 사용자와 영화의 예측 표가 서로 다른 순서로 들어올 때 무엇으로 한 행을 맞추나요?

사용자 ID와 영화 ID의 쌍을 일대일 키로 사용합니다. 중복·누락·초과도 확인합니다.

## 7. 시험에서 최저 RMSE를 보인 비중을 골라 그 오차를 최종 성능으로 보고하면 어떤 문제가 있나요?

시험 자료가 모델 선택에 쓰여 같은 자료에서 선택과 평가가 겹칩니다. 검증에서 선택하고 고정된 시험으로 마지막 평가를 합니다.

## 8. CF 열을 MLP 평점으로 바꾼 연습 10-1에서 어떤 조건을 유지하고 어떤 선택을 다시 하나요?

같은 시간순 분할, 사용자–영화 행, 1–5점 척도를 유지하고 MF 비중을 검증에서 다시 선택합니다.

# W10B · 오토인코더 추천을 한 칸씩 이해하기 · 퀴즈 답안

> 딥러닝응용I(추천시스템) · 동덕여자대학교 · 유원상 교수 · 2026-2

먼저 강의자료의 점검 퀴즈를 풀고 확인하세요. 서술형 문항은 같은 의미의 다른 표현도 가능합니다.

이 답안은 해당 강의의 설명을 바탕으로 정리한 학습용 해설입니다.

## 1. 사용자 기준 AE의 한 입력 샘플은 무엇이며, MF의 ID 입력과 어떻게 다른가요?

한 사용자의 영화별 평점 벡터입니다. MF는 사용자·영화 ID로 잠재벡터를 조회하지만, AE는 훈련 평점 벡터에 공유 인코더와 디코더를 적용합니다. 두 방법 모두 잠재표현을 쓰지만 입력과 계산 경로가 다릅니다.

## 2. 입력이 4차원이고 잠재표현이 2차원일 때, 출력이 다시 4차원이어야 하는 이유는 무엇인가요?

입력의 각 위치가 특정 영화이기 때문입니다. 잠재표현은 2개 값으로 요약하더라도 디코더는 원래 네 영화 위치의 평점을 각각 복원해야 합니다. 배치 B의 모양은 (B,4) → (B,2) → (B,4)입니다.

## 3. 입력 `[2,0,0,−2]`와 E02의 가중치에서 두 잠재 노드의 가중합과 활성값은 각각 무엇인가요?

가중합은 $2(.5)+0(0)+0(.5)-2(0)=1$, $2(0)+0(.5)+0(.5)-2(.5)=-1$입니다. 활성값은 $[\tanh(1),\tanh(-1)]\approx[.761594,-.761594]$입니다.

## 4. 원래 평점3, 훈련 평균3인 관측이 중심화 후 0이 되면, 오차 계산에 포함해야 하나요?

포함해야 합니다. 중심화된 값 0은 평점이 평균과 같다는 뜻일 수도 있습니다. 원자료에서 관측 여부를 먼저 보존하고 손실 마스크로 사용해야 합니다.

## 5. E04의 관측 제곱오차 합 6과 관측 수 3에서 MSE와 RMSE는 각각 얼마인가요?

$\operatorname{MSE}=6/3=2$, $\operatorname{RMSE}=\sqrt2\approx1.414214$입니다. 관측된 세 칸을 사용했다는 점까지 설명합니다.

## 6. 관측 MSE 2와 L1 벌점 .0105가 주어졌을 때, 최적화 목적함수와 순수 RMSE는 어떻게 다른가요?

관측 MSE를 학습하는 설정에서 목적함수는 $2+.0105=2.0105$, 순수 RMSE는 $\sqrt2\approx1.414214$입니다. RMSE를 직접 학습하면 목적함수는 $\sqrt2+.0105\approx1.424714$가 됩니다. 어느 손실을 썼는지 먼저 확인합니다.

## 7. 교재의 `validation_data=(train_data, test_data)`에서 모델 입력과 비교할 정답은 각각 무엇인가요?

입력은 train_data, 비교할 정답은 test_data입니다. 시험 정답을 입력하는 코드라는 해석은 잘못입니다. 다만 같은 시험표를 epoch별 검증과 마지막 평가에 반복 사용하므로, 이번 수업은 훈련·검증·시험 관측을 별도로 나눕니다.

## 8. 같은 관측 분할로 사용자 기준과 아이템 기준을 비교할 때, RMSE 외에 어떤 조건과 수를 함께 기록해야 하나요?

자료 모드와 크기, 같은 관측 분할·훈련 평균·seed, 입력 방향과 폭, 은닉폭·활성함수·정규화·optimizer·학습률, 모수 수·갱신 수·시간, 검증 기준과 선택 epoch, 시험 관측 수와 미학습 축 처리 조건을 기록합니다. 같은 epoch가 같은 계산량을 뜻하지 않습니다.

# W05A · 추천시스템 핵심 복습과 동일 데이터 모델 비교·튜닝·평가 · 퀴즈 답안

> 딥러닝응용I(추천시스템) · 동덕여자대학교 · 유원상 교수 · 2026-2

먼저 강의자료의 점검 퀴즈를 풀고 확인하세요. 서술형 문항은 같은 의미의 다른 표현도 가능합니다.

이 답안은 해당 강의의 설명을 바탕으로 정리한 학습용 해설입니다.

## 1. 아이템 CF와 장르 내용 기반 추천은 영화를 비교할 때 각각 어떤 정보를 사용하는가?

아이템 CF는 여러 사용자가 영화에 준 평점 패턴을 비교하고 대상 사용자가 다른 영화에 준 평점을 집계한다. 내용 기반은 장르 같은 영화의 특징과 사용자 선호 프로필을 비교한다. 같은 영화 간 비교라도 정보의 출처가 다르다.

## 2. 인기 개수와 코사인 점수에 평점 RMSE를 그대로 계산하면 왜 해석이 잘못되는가?

평가 횟수와 코사인은 1–5점 평점 예측이 아니다. 283회 또는0.8을 실제 평점과 빼면 단위가 다른 값을 비교한다. 이번 RMSE/MAE는 해당없음으로 남기고, 같은 후보에서 만든 순위를 P/R/NDCG로 비교한다.

## 3. 절대오차가 [1,1,1,1]과 [0,0,0,4]인 두 모델의 MAE와 RMSE는 각각 얼마인가?

MAE는 둘 다 $4/4=1$점이다. RMSE는 첫 모델 $\sqrt{4/4}=1$점, 둘째 $\sqrt{16/4}=2$점이다. 제곱이 큰 오차의 비중을 키운다. 제곱근은 제곱오차 평균 뒤에 취한다.

## 4. 관련 영화가 {A,C,E}, Top-5가 [A,B,C,D,F]일 때 Precision과 Recall은 얼마인가?

적중은 A와 C 두 편이다. Precision@5는 $2/5=0.4$, Recall@5는 $2/3\approx0.667$이다. 추천한 자리 수와 찾아야 할 관련 영화 수가 각각 분모다.

## 5. 두 추천 목록의 적중 개수가 같아도 NDCG가 달라질 수 있는 이유는 무엇인가?

NDCG는 적중 여부에 위치별 $1/\log_2(j+1)$을 곱해 더한 DCG를 이상적 IDCG로 나눈다. 앞의 적중이 더 큰 기여를 하므로 같은 적중 집합이라도 순서에 따라 달라진다. 이번 예는 약 0.704와 0.384다.

## 6. 이웃 수 k, 추천 수 N, 학습 선호 하한, 평가 관련성 기준은 각각 어느 단계의 설정인가?

k는 CF 점수 생성에 쓸 최대 이웃 수, N은 최종 추천 목록 길이이자 순위 지표 조건이다. 학습 선호 하한은 내용 프로필에 넣을 train 관측을 고르는 모델 설정, 평가 관련성은 정답 집합을 정의하는 조건이다. 이번 관련성은4점으로 고정한다.

## 7. 설정을 validation에서 고른 뒤 최종 test를 평가하는 올바른 학습 순서는 무엇인가?

train에서 평균/프로필/유사도 학습→validation에서 설정 선택→설정 고정→train+validation으로 재학습→최종test 평가다. test 결과로 다시 설정을 고르면 독립적인 최종 평가로 해석할 수 없다.

## 8. 전체 평균 성과와 개별 추천 목록을 함께 확인해야 하는 이유와 이 실험의 한계 한 가지를 설명하라.

평균 성과가 높아도 특정 사용자에게 부적합한 목록이 나올 수 있다. 학습 이력, 장르, 평가 수, 평균 대체 근거와 사용자별 지표를 함께 확인한다. 무작위 관측 분할 한 번이며 시간순 미래/신규 사용자/실제 온라인 만족도를 검증하지 않았다는 한계 중 하나를 구체적으로 설명한다.

# W10A · FM 복습과 딥러닝을 이용한 추천 시스템 · 퀴즈 답안

> 딥러닝응용I(추천시스템) · 동덕여자대학교 · 유원상 교수 · 2026-2

먼저 강의자료의 점검 퀴즈를 풀고 확인하세요. 서술형 문항은 같은 의미의 다른 표현도 가능합니다.

이 답안은 해당 강의의 설명을 바탕으로 정리한 학습용 해설입니다.

## 1. FM의 입력 특성 열 번호와 사용자·영화 번호는 어떻게 다른가요?

FM의 i,j는 입력 벡터의 열 번호다. 사용자·영화 ID를 원핫 블록의 특정 열에 대응시킬 수 있지만 일반 FM에는 맥락 등 다른 열도 있다.

## 2. 활성 특성3개와 잠재폭2일 때 활성 쌍 수와 각 내적 길이는 얼마인가요?

활성 쌍은 $\frac{3\times2}{2}=3$개, 각 내적은 잠재좌표2개의 곱을 더한다. 두 수를 같은 것으로 해석하지 않는다.

## 3. 원핫 벡터와 임베딩 조회가 같은 결과를 주는 이유는 무엇인가요?

원핫의1에 대응하는 행만 남고 나머지는0배되어 사라진다. 동일한 표의 행을 정수ID로 조회하는 것과 같다.

## 4. MF 모델에서 중심화한 목표와 최종 평점 예측은 어떻게 연결되나요?

훈련 평균μ를 평점에서 빼고 모델을 학습한다. 모델의 중심화 예측에 같은 훈련 평균μ를 한 번 더해 평점 척도로 복원한다.

## 5. 배치 크기 B와 사용자 표 행 수 M을 구별해 설명하세요.

B는 현재 처리하는 관측의 수, M은 임베딩 표의 전체 행 수다. 한 사용자가 여러 관측에 나타날 수 있으며 B는 모수 수를 바꾸지 않는다.

## 6. 내적과 Concatenate의 출력 차이는 무엇인가요?

같은 길이K 두 벡터의 내적은 수 하나, Concatenate는 길이2K 벡터다. 연결 자체는 내적이나 상호작용을 계산하지 않는다.

## 7. Dense 뒤의 linear 활성함수는 Dense 층 전체를 없애도 된다는 뜻인가요?

아니다. Dense는 가중합과 편향 zW+b를 계산한다. linear 활성함수가 이 결과를 그대로 통과시킨다는 뜻이다.

## 8. 직업 임베딩3차원을 추가하면 연결 입력 폭은 어떻게 변하나요?

두 K차원 벡터와 두1차원 입력을 연결한2K+2에서2K+5로 증가한다. K200이면402에서405다.

## 9. 검증 자료와 시험 자료는 각각 무엇을 위해 사용하나요?

검증은epoch/설정 선택에 사용한다. 시험은 선택 후 최종 평가에 사용하고 시험 결과로 다시 선택하지 않는다. 평균과 전처리 통계는 훈련에만 적합한다.

## 10. 추가 변수나 더 깊은 모형이 항상 RMSE를 개선하나요?

보장되지 않는다. 같은 데이터 분할·학습예산·평가지표에서 비교하고 모수 증가, 과적합, 변동을 함께 해석한다. 성능 향상은 실제 관측 결과로 판단한다.

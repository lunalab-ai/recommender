# W08A · 중간고사 대비 ③: 5~6주차 핵심 요약과 60문제 · 퀴즈 답안

> 딥러닝응용I(추천시스템) · 동덕여자대학교 · 유원상 교수 · 2026-2

먼저 강의자료의 점검 퀴즈를 풀고 확인하세요. 서술형 문항은 같은 의미의 다른 표현도 가능합니다.

이 답안은 해당 강의의 설명을 바탕으로 정리한 학습용 해설입니다.

## 1. 설명 예제의 MAE와 RMSE가 원래 평점 단위로 해석되는 이유는 무엇인가요? (연결 Q06)

MAE는 평점 차이의 절댓값을 평균하므로 평점 단위입니다. RMSE는 제곱한 평점 차이를 평균한 뒤 제곱근을 취해 원래 평점 단위로 돌아옵니다.

## 2. 설명 예제의 MF 예측에서 사용자·아이템 편향은 각각 어떤 기준 차이를 나타내나요? (연결 Q18)

사용자 편향은 전체 평균에 비해 사용자가 높거나 낮게 평가하는 경향, 아이템 편향은 해당 아이템이 높거나 낮게 평가되는 경향을 반영합니다. 예제의 +0.1과 −0.1은 서로 상쇄되지만 각 역할은 다릅니다.

## 3. 설명 예제에서 p를 먼저 갱신한 뒤 새 p로 q를 계산하면 명시된 동시 갱신과 같을까요? (연결 Q31)

같지 않습니다. 명시된 동시 갱신은 같은 잔차와 old p, old q를 사용합니다. 새 p를 q 계산에 넣으면 다른 계산 순서이며 예제의 q_new=0.436과 달라집니다.

## 4. 설명용 검증 곡선에서 선택 epoch의 번호만 저장하면 충분한가요? (연결 Q39)

충분하지 않습니다. 선택 epoch의 P, Q와 사용자·아이템 편향을 모두 복사해 저장하고 복원해야 그때의 예측을 재현할 수 있습니다.

## 5. 설명 예제의 SVD 에너지 보존율 90%를 추천 정확도라고 부를 수 있나요? (연결 Q58)

부를 수 없습니다. 90%는 주어진 입력 행렬 제곱합의 보존 비율이며, 숨긴 실제 평점이나 추천 순위의 정확도는 별도 자료와 지표로 평가해야 합니다.

# 과제 1 · 소소상점 추천 출시 심사

**개인 과제 · 11월 24일(화) 시작 · 12월 4일(금) 23:59 마감(KST)**

소소상점의 추천 담당자로서 한 모델의 출시를 제안합니다. 수업에서 시작한 [Colab 사본](https://colab.research.google.com/github/lunalab-ai/recommender/blob/2026-fall-w13a-r2/notebooks/student/w13a-first-recommendation.ipynb)을 이어서 씁니다. CPU에서 개인별로 진행하며 생성형 AI는 사용하지 않습니다.

## 1. 무엇을 개선할지 정합니다

- Colab 1절에서 지표 하나를 고릅니다. **Hit@5**는 가린 상품이 추천 5개 안에 들어온 비율입니다. **NDCG@5**는 맞힌 상품의 순위가 높을수록 더 큰 값을 줍니다.
- 어떤 장바구니에 어떤 변화가 생길지 한 줄로 예상합니다. “한 상품만 담긴 주문에서는 동시구매 하한을 높이면 추천 후보가 줄 것이다”처럼 관찰할 대상을 고릅니다.

## 2. 모델을 만들고 7~10개 실험을 비교합니다

Colab 2~4절에서 코사인 계산, 잠재요인 점수 행렬, 후보 제외와 두 점수 결합을 작성합니다. 5절에서 아래 네 종류를 같은 검증 주문 674건으로 비교합니다.

| 종류 | 최소 실험 수 | 바꾸는 설정 |
|---|---:|---|
| 인기순 | 1 | 제공된 기준 |
| 아이템 CF | 2 | 최소 동시구매 횟수 1·3·5 중 서로 다른 두 값 |
| 절단 SVD 잠재요인 | 2 | 잠재 차원 8·16·32 중 서로 다른 두 값 |
| CF + 잠재요인 | 2 | 하한·차원 고정, 잠재요인 비중만 1~99%에서 다르게 |

Hit@5와 NDCG@5, 적중 건수 및 한 품목·여러 품목 장바구니의 Hit@5가 자동으로 기록됩니다. **1절에서 선언한 지표가 가장 높은 실험**을 선택합니다. 그 지표가 같으면 해당 실험 중 하나를 고릅니다.

## 3. 출시 화면에서 순위가 바뀐 상품을 찾습니다

1. Colab 6절에서 검증 때 사용한 순위 함수를 화면에 연결합니다.
2. 7절에서 출시할 실험과 비교할 실험 하나를 고릅니다. 같은 장바구니에서 순위가 다른 상품 하나의 번호를 기록합니다. 5위 밖은 0으로 기록됩니다. 관찰 상품은 장바구니에 담긴 상품을 제외하고 고릅니다.
3. 선택 근거와 평가 한계를 한 줄씩 적습니다. 근거에 우선 지표와 관찰한 상품의 순위 변화를 활용하세요. 채점 도구는 실험 ID·지표·상품번호·순위를 재현하고 두 문장의 입력 여부를 확인합니다.

## 4. ZIP 한 개를 냅니다

Colab 7절에서 만든 폴더 `w13a-project-r2`의 `shop.html`을 내려받아 브라우저에서 엽니다. 장바구니와 두 실험을 바꾸고 **검증 기록**에서 출시 행을 확인합니다. 같은 폴더에서 `w13a-assignment1.zip`을 받아 SmartClass 과제 메뉴에 한 개 올립니다. ZIP에는 `shop.html`, `submission.json`, `metrics.csv`, `student_model.py`가 들어 있습니다. 화면 캡처는 채점 도구가 생성합니다.

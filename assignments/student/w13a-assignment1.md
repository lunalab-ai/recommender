# 과제 1 · 첫 추천 출시

**개인 과제 · 11월 24일(화) 시작 · 12월 4일(금) 23:59 마감(KST)**

온라인 소품 편집숍에 첫 추천을 적용합니다. 같은 주문의 품목 하나를 가리고 네 가지 추천을 비교한 뒤, 출시할 한 가지를 자기 쇼핑몰에 적용하세요. 예상 45~60분입니다.

## 1. 실습을 이어서 열기

- [W13A Colab](https://colab.research.google.com/github/lunalab-ai/recommender/blob/2026-fall-w13a/notebooks/student/w13a-first-recommendation.ipynb)의 자신의 사본을 열고 CPU에서 위부터 실행합니다.
- 4절의 두 함수에 각각 `return` 식 한 줄을 작성합니다. 함수 이름과 인수는 그대로 둡니다. 첫 함수에서는 제공된 `sqrt`를 사용합니다. 새 패키지나 파일 입력은 필요하지 않습니다.
- 5절의 공개 검사에서 두 항목을 통과시키고 비교표를 만듭니다. 도움말은 [W04B E1·E3](https://colab.research.google.com/github/lunalab-ai/recommender/blob/2026-fall-w04b/notebooks/student/w04b-cf-synthesis.ipynb)에 있습니다.

## 2. 네 행을 비교하고 출시 모델 선택

| 실행 행 | 추천 방식 | 최소 동시구매 횟수 |
|---|---|---:|
| popularity | 인기순 | 해당 없음 |
| cf-1 | 아이템 CF | 1 |
| cf-3 | 아이템 CF | 3 |
| cf-5 | 아이템 CF | 5 |

같은 검증 주문과 후보에서 추천 5개를 평가합니다. 표의 검증 주문 수, 적중 건수, `Hit@5`와 `NDCG@5`를 확인하세요. **Hit@5가 가장 높은 행**을 고르고, 동점이면 **NDCG@5가 높은 행**을 고릅니다. 두 지표가 같으면 해당 행 중 하나를 선택하세요. 숫자는 실험에서 자동으로 저장됩니다.

## 3. 쇼핑몰 확인과 제출

1. 6절을 실행해 `shop.html`을 받습니다. Colab의 파일 패널에서 열거나 다운로드 셀의 변수를 켜서 받습니다.
2. 다운로드한 HTML을 브라우저에서 열고, **실험 통계**에서 출시 행을 선택합니다. 상품 둘러보기로 돌아와 케이크 스탠드를 담고 추천이 갱신되는지 봅니다. 담은 상품이 추천 목록에 다시 나오지 않아야 합니다.
3. **실험 통계 → 제출 ZIP 받기**로 `w13a-assignment1.zip`을 받아 SmartClass의 해당 과제 메뉴에 한 개 올립니다.
4. ZIP의 네 파일을 확인하세요. `shop.html`, `submission.json`, `metrics.csv`, `student_model.py`입니다. 네 행의 결과와 선택은 자동으로 기록됩니다. ZIP 대신 폴더나 이미지 파일을 올리지 않습니다.
